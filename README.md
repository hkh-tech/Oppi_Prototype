# Õppi | AI-Powered Accessible Learning Platform

A bridge that connects learning and accessibility through AI.

## About
Õppi is an independent AI research initiative exploring how 
technology can make education more accessible and inclusive 
for users with diverse needs. The platform combines 
human-centred design with AI to create equitable learning 
experiences.

## Features
- AI-powered accessible learning tools
- Inclusive interface design
- Human-centred UX research and prototyping

## Design Collaboration
This project includes a Figma prototype developed in 
collaboration with DiAmíti, an accessible interface design 
studio. Their mentorship and design expertise shaped the 
visual and interaction design of Õppi, with connections 
growing across Costa Rica 🇨🇷

## Tech Stack
- Figma (UI/UX prototyping)
- AI integration (in development)

Accessibility · Inclusive Design · AI for Education ·
